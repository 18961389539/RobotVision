## 二、本次新修复

### 2.1 ImageAnalysisService 静态缓存竞态（真实并发缺陷）

`Services/ImageAnalysisService.cs:35` `GetNormalizedPixels`：原实现 `TryGetValue` 先查后 `Add`——分析命令并发触发首帧同 key 时，两线程同时 miss → 二次 `Add` 抛 `ArgumentException`（早间深挖已标记 P2-3 但未修，本次补上）。

**修复**：改用 `ConditionalWeakTable.GetValue(bitmap, static key => …)` 原子工厂语义——同 key 并发只执行一次构建，消除竞态且语义更清晰（`NormalizeBitmap` 为静态，可在静态 lambda 内调用）。验证：编译 0 错误，ImageViewerControl.Tests 56/56。

### 2.2 CA2213 误报标注（Wpf 达成 0 警告）

剩余 2 个 CA2213 均为**跨路径释放误报**（分析器无法追踪），按 BaslerCamera 既有先例加 `[SuppressMessage]` + Justification：
- `App._host`：由 `ApplicationShutdownCoordinator.Shutdown` 释放（StopAsync 成功后，带超时）
- `CamerasViewModel._previewSessionCamera`：由 `DisposePreviewSessionCore`（跨 partial 文件）释放

效果：**Wpf 工程 0 警告 0 错误**（此前 8 个）。Hosting 层 8 个警告全部来自 `LoggerMessage.g.cs` 源生成器产物（非手写代码，不可改，接受）。
